This project is a Machine Learning-based Heart Disease Prediction System that predicts the likelihood of heart disease using patient medical data. It helps in early detection and supports better healthcare decisions.

📌 Project Overview

The model is trained on clinical features such as:

Age
Sex
Chest Pain Type
Resting Blood Pressure
Cholesterol Level
Maximum Heart Rate
Fasting Blood Sugar
ECG Results

The system uses these inputs to classify whether a person is at risk of heart disease.

📊 Dataset
Dataset used: [UCI Heart Disease Dataset / Kaggle Dataset / Heart.csv]
Number of records: [918]
Number of features: [12]
